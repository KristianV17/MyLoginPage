# MyLoginPage

Šolski projekt iz HTML in CSS: poustvaritev strani za prijavo in registracijo v slogu Epic Games.

## Kaj vsebuje

| Datoteka | Opis |
|---|---|
| `login.html` | Prijavna stran: logotip, polje za e-pošto, gumb **Continue**, gumbi za prijavo prek drugih računov, povezava **Create an account** |
| `registracija.html` | Registracija ("Add your details"): e-pošta, ime, priimek, geslo, prikazno ime, potrditvena polja za pogoje uporabe in gumb **Continue** |
| `stylesheet.css` | Skupni slogi obeh strani (temna tema, osrednja škatla, gumbi, vnosna polja) |

## Zagon

Odpri `login.html` v brskalniku. Povezava **Create an account** vodi na `registracija.html`, gumb **Back** pa nazaj na prijavo.

## Tehnologije

- HTML5
- CSS3

Obrazca nimata zalednega dela, zato se podatki nikamor ne pošiljajo.
